# Data sources and licence

## UKCS field production

Publisher: North Sea Transition Authority (NSTA).

Dataset: UKCS hydrocarbon field production reports - PPRS points, WGS84.

Dataset page: https://www.data.gov.uk/dataset/e2c7af85-8b52-4ecc-ab8d-c4f0639d5459/ukcs-hydrocarbon-field-production-reports-pprs-points-wgs84

Project snapshot downloaded: 3 October 2026.

Snapshot SHA-256: `108817ba9272115f24d8275c19fb578ae3a83e96c42fd72add2cbee3e50c7689`.

The source contains monthly field/reporting-unit production data. This project uses the five complete calendar years 2021-2025; incomplete 2026 records are deliberately excluded.

## Brent benchmark price

Publisher: US Energy Information Administration (EIA).

Series: Europe Brent Spot Price FOB, monthly, dollars per barrel.

Series page: https://www.eia.gov/dnav/pet/hist/leafhandler.ashx?f=m&n=pet&s=rbrte

The project reference file transcribes the 60 published monthly values for January 2021 through December 2025.

Reference-file SHA-256: `87ec488fa25b5c4c8be4d221dad8c85a37d01b6e388aab8795a206846461d3e4`.

## Use and reproducibility

The analysis retains the original NSTA snapshot and a small human-readable EIA price table. Public data may be revised after the recorded access dates. Users should re-download the source when they require the latest regulatory reporting position.
